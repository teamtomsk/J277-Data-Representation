03 / Explore ASCII · 7 minutes

Same character. Agreed code.

ASCII is a standard character set. Its agreed codes let computers represent and exchange text. Choose a group, then select a character.

8-bit binary

Why are there eight bits here?

Original ASCII has 128 codes and uses seven bits. We show those codes with a leading 0 to make eight bits, as OCR does in exam questions. Eight bits have 256 possible patterns, but original ASCII uses only 128 of them.

Use the pattern

Teacher notes, sources & saved work

Lesson 5 of a two-lesson sequence, adapted from Raspberry Pi’s “Lesson 5 and 6 Characters” and T3 worksheets. Core: character sets, binary codes, ASCII ordering and bits versus capacity. Unicode is a short extension; fuller comparison and text versus numerical values are reserved for Lesson 6.

Aligned to the Characters content in OCR J277, 1.2.4. OCR uses eight-bit representations for ASCII questions and does not require memorised character codes. Original ASCII uses seven bits / 128 codes; no claim is made that it contains 256 characters. The two-bit symbol set is invented for teaching, not ASCII.

The opening explorer accepts up to 12 characters and displays printable ASCII only. Unsupported characters are flagged, never silently replaced with incorrect ASCII codes. Storage totals assume one byte per ASCII character, excluding file metadata. The Unicode extension uses fixed single-code-point examples; see the Unicode encoding FAQ.
