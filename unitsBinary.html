01 / Units & binary

Two states, endless possibilities.

A bit is a binary digit: 0 or 1. Electronic circuits represent these with two distinguishable states. Our switches use off and on as a simple model.

Make a pattern

Every extra bit doubles the number of possible patterns. These are signal states, not the whole computer being switched off.

All kinds of data

Numbers, words, photos, sound and program instructions are represented using patterns of bits. We will focus on whole numbers today.

Denary (decimal): base 10, using digits 0–9.
Binary: base 2, using only 0 and 1.

02 / Units & binary

How much data?

Start small: 1 bit, 4 bits in a nibble, 8 bits in a byte. From bytes upwards, each larger unit is 1,000 times the previous one in this lesson.

Explore the units

KB → MB → GB → TB → PB
Kites Make Great Toy Planes. Going to a smaller unit? Multiply by 1,000 for each step. Going to a larger unit? Divide.

B means bytes; b means bits. The bits ↔ bytes conversion uses 8, not 1,000. A byte does not always equal one text character; that depends on the encoding.

03 / Units & binary

Switch on the place values.

In denary, each column is worth ten times the one to its right. In binary, each is worth twice as much. A 1 includes that column’s value; a 0 leaves it out.

Leftmost: most significant bit (MSB), weight 128 in an 8-bit number.
Rightmost: least significant bit (LSB), weight 1.

Eight bits make 256 patterns. For unsigned whole numbers, they represent 0–255. Leading zeros do not change the value.
